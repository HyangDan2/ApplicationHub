# Legacy EduHub documents

These guides describe the **retired** learning-archive product that this repository hosted until 2026-11-10, when `HyangDan2/EduHub` was renamed to `HyangDan2/ApplicationHub` and rebuilt as a catalog of HD2Lab's browser apps.

They are kept unchanged for reference: record schema, Markdown detail pages, the EDPilot0001 course contract, and the course-to-hub return flow no longer exist in this codebase. Current behavior is described in [../OPERATIONS.md](../OPERATIONS.md), [../../README.md](../../README.md), and [../../AGENTS.md](../../AGENTS.md).

| Document | Former purpose |
|---|---|
| `EDUHUB_GUIDE.md` | Learning record authoring, catalog fields, and Markdown detail pages |
| `EDUHUB_INTEGRATION_GUIDE.md` | Hub hierarchy EduHub ↔ EDPilot0001 → Web-HQ |
| `EDUHUB_MATERIAL_PORTING_GUIDE.md` | Porting external study material into a record |
| `EDUHUB_RETURN_GUIDE.md` | Course-side return link contract |

The Machine Learning Lab card (`EDPilot0001`) is now a plain launch card. The course site keeps its own header and back link, which belong to the `HyangDan2/EDPilot0001` repository.
